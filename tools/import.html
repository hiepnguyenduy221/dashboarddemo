Nhập dữ liệu dashboard

Chọn file Excel theo template → kiểm tra → xem trước → lưu data.json vào thư mục gốc repo, rồi commit và push.

  1. 1. Chọn file
  2. 2. Kiểm tra
  3. 3. Xem trước
  4. 4. Lưu data.json

Khi lưu, chọn file data.json ở thư mục gốc repo để ghi đè (Chrome/Edge). Trình duyệt khác sẽ tải file về; chép file đó vào thư mục gốc repo.

Lỗi

    Cảnh báo

      Có lỗi thì không lưu được — sửa Excel rồi chọn lại file. Cảnh báo là chỗ số không khớp nhau; nên xem lại nhưng vẫn lưu được. Cùng quy tắc với python tools/excel_to_json.py.
